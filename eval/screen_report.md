# 逆向筛选结果（虚拟筛选 Demo）

**任务**：给定目标能隙窗口 5.5–6.5 eV，从 133,802 个 QM9 分子中筛出可用候选。

**筛选流程**（四步，全部可复现）：

1. OOF 预测值落窗 → 命中 39855 个
2. 只保留落在适用域内的分子 → 38097 个（剔除模型"没见过"的结构）
3. 按树间标准差升序排序 → 模型最确定的排前面
4. Bemis-Murcko 骨架去重，每种骨架只留 1 个 → 最终 40 个候选，覆盖 40 个不同骨架

**候选质量**：这 40 个分子的真实 DFT 能隙中位绝对误差 0.021 eV，
即筛选出来的不仅"预测值符合窗口"，"实际值也基本在窗口附近"。
