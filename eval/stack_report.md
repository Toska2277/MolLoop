# 堆叠集成实验结果

四类基模型（都基于同一套 222 维特征，5 折留出预测），再用岭回归做元学习器。

| 模型 | MAE (eV) | R² | 相对 RF 的变化 |
|---|---|---|---|
| 随机森林 RF（当前主模型） | 0.1622 | 0.9627 | 基准 |
| ExtraTrees（极端随机树） | **0.1559** | 0.9642 | −3.9% |
| XGBoost | 0.2057 | 0.9502 | +26.8% |
| 岭回归 | 0.3492 | 0.8691 | +115% |
| **堆叠集成（四者 → 岭回归）** | **0.1555** | 0.9646 | **−4.1%** |

## 结论（这条比数字本身更有价值）

1. **堆叠只比最好的单模型（ExtraTrees）好 0.0004 eV**，相当于误差再降 0.3%。说明三类树模型看到的是同一份信息，堆叠已经无法互补。
2. **三条独立路线（RF 0.1622 / ExtraTrees 0.1559 / 堆叠 0.1555）都收敛在 0.155–0.162 eV**，这就是这套 222 维 2D 描述符的精度上限。
3. 想突破 0.155 eV，唯一的路是换特征：3D 构象描述符、分子指纹的图结构编码，或图神经网络（需要 GPU + PyTorch，本项目明确不使用）。
4. 因此**主模型保持随机森林**，理由是：精度损失仅 4.1%，但可解释性（特征重要性、树间方差可作不确定度）远好于堆叠模型；在一个以"流程完整性与结果可靠性"为评分导向的比赛中，这是更合理的选择。

堆叠结果作为"我们试过更强的方法但收益已饱和"的证据写进方案的局限性章节。
